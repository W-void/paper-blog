## 🧭 方向性归纳

### 1. 生成式推荐走向生产：准、省、快，一个都不能少

本周最有分量的集群。快手系两篇代表了 GR 在业务侧的成熟度：[TriGen](https://arxiv.org/abs/2611.16395) 解决"点击触发的即时推荐"与"长期偏好推荐"的结构性张力，用校准尾部注入 + 动态门控让一套生成模型同时接住冲动和品味，六国市场全量上线；[ReSID](https://arxiv.org/abs/2611.16404) 则是首个系统研究 GR 长尾可达性的工作，把"建 ID → 解码 → 匹配"全链路当水管逐段查漏，长并行 SID + 流行度去偏 beam search + 部分 SID 匹配，长尾召回 SOTA 且已服务主流量。腾讯 [TokenFormer V2](https://arxiv.org/abs/2611.19074) 把"表达分辨率"和"交互密度"解耦，以 1/5 的 FLOPs 拿到统一推荐 top 精度并带在线 A/B。

效率侧同样热闹：[RecMem](https://arxiv.org/abs/2611.17921)（NeurIPS 2026）用 16 个循环记忆槽替代 1200-token 全量历史，只损失 12% Recall@10，还给出不随历史长度增长的偏差上界；[LQ-Rec](https://arxiv.org/abs/2611.25256) 把离散化推迟到流水线末端，换来"排序质量随语义 ID 变长单调提升"的理论保证和免重训的随时压缩；[CACO](https://arxiv.org/abs/2611.25738) 则盯上了连续生成式检索里"多个查询扎堆同一片近邻区域"的浪费，用免标注的覆盖目标把查询间重叠砍掉 53%~65%。搜索侧，[IntentGR](https://arxiv.org/abs/2611.22788)（KDD 2027）把 query 语义注入 tokenization、训练分布、解码全链路，工业电商数据 Recall@10 +11.96%；[CG2R](https://arxiv.org/abs/2611.22163) 让聚类先验直接进打分公式，毫秒级延迟可做一阶段召回。淘宝的[整页生成式重排](https://arxiv.org/abs/2611.25527)则把生成式思路推到"整页决策"，用局部页面级目标解决 credit assignment 粗糙和 off-policy 滞后两大老毛病。

### 2. 生成式推荐 × RL：红利、陷阱与信息量更大的奖励

[Better Rankers, Worse Retrievers](https://arxiv.org/abs/2611.22838) 是本周最值得细读的一篇：RL 后训练提升小 K 的 hit@K，却在数百 K 的候选召回上劣于 SFT——因为日志里每用户只有一个真实下一物品，rollout 中的其他合理候选全被当成"错误"惩罚，而这些恰恰是相似用户真正会选的东西。解法轻量得漂亮：加一项 out-of-rollout anchoring 保住 SFT 对未采样物品的排序即可。[VerRec](https://arxiv.org/abs/2611.22410) 从奖励形态下手，让用户模拟器用自然语言写"评语"告诉模型差在哪，GRPO 联合优化，探索更丰富且推理时零开销。[SimRec](https://arxiv.org/abs/2611.15426) 更进一步，用 RL 端到端训练推荐智能体的完整交互策略（搜索、反问、推荐），4B 小模型打平更大的免训练智能体。姊妹篇 [ReAlign](https://arxiv.org/abs/2611.15445) 把"重排版 RLHF"带进生成式重排，配 [SurvEval](https://arxiv.org/abs/2611.15434) 的生存分析式列表评估器组成组合拳。

### 3. LLM + 推荐：可读、可编、可信

Meta 的 [CLEAR](https://arxiv.org/abs/2611.19110) 是本周工程含量最高的系统工作：把推断出的兴趣写成一句句可读、可增删的人话，兴趣同时是展示层、检索入口和归因单元，88.5% 的展示兴趣被用户人工评审认可，自研 3B 生成器 F1 还超过了 Gemini 2.5 Pro。可信化三件套同样齐整：[GuardAgent](https://arxiv.org/abs/2611.22274)（WSDM 2027）首次系统研究 LLM 推荐中的对抗性营销攻击——在 LLM 推荐里文字就是生成指令本身，攻击面已根本改变；[PGPO](https://arxiv.org/abs/2611.23236)（EMNLP 2026）提出 relational fidelity 的隐私防御思路，允许语义整体偏移但保住物品间相对关系，防 embedding 反演而不伤推荐；[冗长偏差审计](https://arxiv.org/abs/2611.18878)用随机改写构造零标注统计检验，证明 9 个 LLM 推荐器无一幸免地偏爱更长的商品描述（最高 +38% odds/标准差）。质量侧，[ReflectRec](https://arxiv.org/abs/2611.23969) 给 CoT 推荐装上"往返验证器"（偏好描述能否复原用户历史），MovieLens 上 Hit@10 比 CoT4Rec-ICL 高最多 16 个点；[Evidence Diet](https://arxiv.org/abs/2611.20837) 证明 LLM ranker 真的在读图证据的"归属"而非数量，把候选证据张冠李戴会显著崩盘。

### 4. CTR/排序模型：深度堆叠与算力分配的再思考

淘宝 [DNA](https://arxiv.org/abs/2611.25659) 诊断出交叉注意力堆层数收益递减的根因——每层都在反复读同一份定死的行为序列，于是让序列随深度"进化"（行为 token 按请求自更新、候选间共享），同等 FLOPs 下 AUC +0.08~0.26pt，已部署淘宝搜索（CTR +0.8%）。工业界的另一笔真实账来自 [X-split Argus](https://arxiv.org/abs/2611.24283)：把用户历史离线压缩成可复用记忆 token 供所有候选共用，A/B 转化价值 +4.65%、点击 +2.96%，代价是推理成本 +15%。阿里 [RACE](https://arxiv.org/abs/2611.18244)（WSDM 2027）则提出"按请求不确定性分配算力"：心里有底的请求走瘦身模型，没底的才上完整火力。另有一篇[窗口杠杆](https://arxiv.org/abs/2611.26521)提醒：把观测窗口从 8 周拉到 16 周，收益比堆数据、堆容量、换架构高一个数量级——很多时候加长历史比加模型便宜得多。

### 5. 评测、基准与实验方法：给离线指标照妖镜

[KuaiRecV2](https://arxiv.org/abs/2611.16795)（NeurIPS 2026）正面回应"离线涨点、线上扑街"：千万级多模态物品、30 天真实交互、动态候选池，且规则苛刻——必须同时改进检索、多样性、多任务全指标才算真进步。[用 scaling law 省掉全量 A/B](https://arxiv.org/abs/2611.13539) 发现特征变更下性能随规模的变化遵循可预测规律，小流量实验 + 统计推断即可外推全量效果，在 40+ 种变更上验证有效。防作弊方面，[INTENT](https://arxiv.org/abs/2611.13069) 审计 59 个数据集只留 5 个，还发现"重复用户上一个物品"的无参基线在 4/5 数据集的新物品格登顶；[IntentTwin](https://arxiv.org/abs/2611.12918) 揭露离线基准的"候选支持混淆"——靠支持集归属就能作弊拿满分。还有一篇值得社会层面关注的研究：[生成式新闻推荐会复现流行度](https://arxiv.org/abs/2611.25606)，2000 万条会话上训练 Llama 3 发现，流行度偏见有一条新路径——高频标题被模型逐字记背后在宽 prompt 范围内被复现，去流行化有真实的精度代价。

### 6. 责任推荐与超越相关性

NYU 的[好奇心推荐](https://arxiv.org/abs/2611.14938)把心理学信息缺口理论做成五公理下的可计算度量，在亚洲某头部视频平台全量上线，CTR/播放量/时长全面显著提升——"超越相关性"从口号第一次走完公理化→测量→线上验证的闭环。[MitiHarm](https://arxiv.org/abs/2611.15160)（TPAMI）则完成有害内容传播的测量→实证→缓解全流程：用户确实更爱点有害内容，主流推荐方法在助推扩散，但把危害性信号融入表示学习可以在不牺牲满意度的情况下显著抑制。

## 🔍 横向对比

**GR 落地派的共同选择：先修"结构性缺陷"再谈涨点。** 对比本周 GR 论文会发现一个清晰的分野：学术侧还在堆架构（如[多选题辅助任务](https://arxiv.org/abs/2611.19320)这种低成本高回报的训练技巧，TIGER NDCG@10 最高 +79%），而工业侧的火力集中在修 GR 的三个结构性缺陷——触发意图接不住（TriGen 的动态门控）、长尾写不出来（ReSID 的可达性分析）、算力烧不起（TokenFormer V2 的分辨率-交互解耦、RecMem 的记忆压缩、LQ-Rec 的晚量化）。值得注意的是这批工作给出的答案高度相似：**都在做"分解+按需分配"**——TriGen 分解持久品味与即时冲动，TokenFormer V2 分辨率与交互密度，RACE 按不确定性分配算力，RecMem 按语义保真度分配记忆槽。当 GR 从"能不能生成"进入"划不划算"阶段，资源分配视角正在取代表征学习视角成为主要矛盾。

**RL 后训练：一篇冷水与三杯热饮的互证。** [Better Rankers, Worse Retrievers](https://arxiv.org/abs/2611.22838) 的根因分析（单正样本日志导致合理候选被系统性惩罚）恰好解释了为什么 [VerRec](https://arxiv.org/abs/2611.22410) 的语言化反馈有效——语言化反馈携带"错在哪个维度"的信息，天然缓解了标量奖励"一刀切判错"的信息贫乏；而 [SimRec](https://arxiv.org/abs/2611.15426) 的全轨迹奖励记账也是同一个思路的 agent 版延伸。三篇合起来读，能看出 GR×RL 的演进方向：**从"给更准的分数"转向"给更有信息量的反馈"**。这也和 Tuesday 那篇[冗长偏差审计](https://arxiv.org/abs/2611.18878)形成有趣呼应——LLM 系统里"模型读了什么"越来越决定输出质量，奖励和证据的工程化正在成为新的主战场。

**LLM+推荐的可信化在三个层面同时展开，且互为前提。** 用户层的 [CLEAR](https://arxiv.org/abs/2611.19110)（可读可编辑）、模型层的 [ReflectRec](https://arxiv.org/abs/2611.23969)（自我校验）和平台层的 [GuardAgent](https://arxiv.org/abs/2611.22274)/[PGPO](https://arxiv.org/abs/2611.23236) 看似独立，实则共享一个判断：当推荐从"打分"变成"生成"，**可控性不能靠事后过滤，必须内建到表示和流程里**。CLEAR 把兴趣做成权威偏好状态、GuardAgent 用记忆循环持续进化检测能力、PGPO 保相对关系弃绝对位置，本质都是把"可验证的结构"嵌入生成过程。相比之下，Evidence Diet 的证据归属实验是个及时的提醒：LLM 会认真读你给的结构——给错了比不给更糟。

**评测侧的集体反思指向同一结论：离线榜山的含金量在贬值。** [KuaiRecV2](https://arxiv.org/abs/2611.16795) 的"全指标同涨才有效"、[INTENT](https://arxiv.org/abs/2611.13069) 的"无参基线登顶新物品格"、[IntentTwin](https://arxiv.org/abs/2611.12918) 的"支持集作弊"、[记忆化研究](https://arxiv.org/abs/2611.25606)的"模型爱复述爆款"，从四个不同角度指向同一件事——离线指标的上涨可能来自捷径而非能力。而 [scaling-law 实验法](https://arxiv.org/abs/2611.13539)和 KuaiRecV2 的应对策略也一致：**收紧判定标准、引入规模或行为维度做交叉验证**。对做模型迭代的团队，本周这组论文合起来几乎是一份"离线评测避坑清单"。
