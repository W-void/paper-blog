## 缺口：残差连接的"盲区"

现代大语言模型几乎无一例外地使用 PreNorm + 残差连接。这套组合的逻辑很清晰：残差提供梯度高速公路，让深层网络得以稳定训练。但它有一个被长期忽视的副作用——**深度维度上的信息聚合方式从未被认真设计过**。

把残差展开来看，第 $l$ 层的输入其实是所有前层输出的等权求和：$h_l = h_1 + \sum_{i=1}^{l-1} f_i(h_i)$。每一层的贡献权重都是固定的 1，没有任何机制让某一层说"我现在更需要第 3 层的信息，而不是第 10 层的"。这就是问题所在。

PreNorm 让这个问题更严重。由于每层都在归一化后的输入上操作，隐藏状态的模长随深度线性增长（$O(L)$），越深的层越难对最终输出产生影响——它必须学出越来越大的输出才能"被听见"。这就是所谓的 **PreNorm 稀释问题**（PreNorm dilution）。实验也印证了这一点：大量研究发现，LLM 中相当比例的层可以直接剪掉而几乎不影响性能，说明这些层的贡献已经被淹没了。

序列维度上，Transformer 早就用注意力机制解决了类似问题——每个位置可以选择性地关注序列中任意其他位置，而不是只能看到一个压缩的历史状态。但**深度维度上，这个"从 RNN 到 Transformer"的跃迁从未发生过**。

## 增量：把注意力机制搬到深度轴上

这篇论文的核心贡献一句话说清楚：**把序列维度上"RNN→Transformer"的跃迁复制到深度维度上**——用 softmax 注意力替换固定权重的残差累加，让每一层都能选择性地从所有前层输出中检索信息。

Before this paper：每层只能接收一个等权累加的历史状态，无法区分哪层的信息更有用。

After this paper：每层持有一个可学习的伪查询向量 $w_l \in \mathbb{R}^d$，通过 softmax 注意力对所有前层输出计算权重，实现**内容感知的深度维度信息检索**。

## 核心机制：AttnRes 内部怎么转的

### Full AttnRes

第 $l$ 层的输入从原来的等权求和变为：

$$h_l = \sum_{i=0}^{l-1} \alpha_{i \to l} \cdot v_i$$

其中 $v_0 = h_1$（词嵌入），$v_i = f_i(h_i)$（第 $i$ 层的输出），注意力权重为：

$$\alpha_{i \to l} = \frac{\exp(w_l^\top \text{RMSNorm}(v_i))}{\sum_{j=0}^{l-1} \exp(w_l^\top \text{RMSNorm}(v_j))}$$

关键设计：查询 $w_l$ 是**每层独立的可学习参数**，与当前输入无关（input-independent）。这个选择不是偷懒，而是经过权衡的——input-dependent 的查询（从当前隐藏状态投影）确实能再降 0.006 的 loss，但会引入 $d \times d$ 的投影矩阵，且解码时需要顺序访问内存，工程代价不划算。

RMSNorm 加在 key 上的作用：防止某些层因为输出模长天然偏大而垄断注意力权重。

### Block AttnRes：让它在大规模训练中可用

Full AttnRes 的内存开销是 $O(Ld)$——需要保存所有前层输出。在大规模训练中，激活重计算和流水线并行是标配，这意味着这些输出必须显式保存并跨流水线阶段传输，代价不可接受。

Block AttnRes 的解法：把 $L$ 层分成 $N$ 个块，每块内部用普通残差累加，跨块之间才做注意力。具体地，第 $n$ 块的表示是块内所有层输出之和：$b_n = \sum_{j \in B_n} f_j(h_j)$。跨块注意力只在 $N$ 个块级表示上进行，内存从 $O(Ld)$ 降到 $O(Nd)$。

```
块内结构（以一个块为例）：
                    ┌─────────────────────────────────┐
  b_{n-1} ──→ AttnRes ──→ Attention ──→ 部分和 b_n^1
                    │
  b_{n-1} ──→ AttnRes ──→ MLP ──→ 部分和 b_n^2
                    │
                    └──→ ... ──→ b_n（完整块表示）
```

实验发现 $N \approx 8$ 就能恢复 Full AttnRes 绝大部分的收益，而内存开销只需保存 8 个隐藏状态。

### 工程优化：让它在流水线并行下也高效

**跨阶段缓存**：流水线并行中，每个物理节点处理多个虚拟阶段。朴素实现每次阶段切换都要传输所有累积的块表示，通信量是 $O(C^2)$。缓存优化让每个节点记住已收到的块，每次只传输增量，通信量降到 $O(P^2)$，节省 $V$ 倍（$V$ 是每个物理节点的虚拟阶段数）。

**两阶段推理**：推理时，块内所有层的伪查询 $\{w_l\}$ 都是已知的（它们是模型参数，不依赖输入），可以一次性批量计算跨块注意力（Phase 1），再顺序处理块内依赖（Phase 2），通过 online softmax 合并结果。这把每层的内存访问从 $O(N)$ 次降到均摊 $O(N/S + 3)$ 次，实测推理延迟增加不超过 2%。

## 关键概念费曼讲解

### 概念一：PreNorm 稀释问题

想象你在一个大型会议上做笔记。每次有人发言，你都把他说的话加进你的笔记本。但你的笔记本有个奇怪的规则：每次加新内容之前，你必须把整本笔记压缩成固定大小的摘要，然后再在摘要上加新内容。

问题来了：笔记本越来越厚（模长增长），但每次新发言者的贡献相对于整本笔记的比例越来越小。到了会议后期，即使有人说了非常重要的话，它在你的笔记里也只占很小的比重——被前面所有人的发言"稀释"了。

PreNorm 就是这个情况：归一化操作让每层的输入保持固定尺度，但累积的残差流越来越大，每一层新的贡献相对越来越微弱。

### 概念二：深度维度的注意力权重矩阵 M

把一个 $L$ 层网络的所有层间信息流用一个矩阵 $M \in \mathbb{R}^{L \times L}$ 来描述，其中 $M_{i \to l}$ 表示第 $l$ 层对第 $i$ 层输出的权重。

标准残差：$M$ 是全 1 的下三角矩阵——每层对所有前层一视同仁。

Highway 网络：$M$ 是 1-半可分矩阵——权重通过门控的累积乘积传播，仍然是递推结构。

mHC（多流超连接）：$M$ 是 $m$-半可分矩阵——维护 $m$ 条并行流，相当于深度维度上的线性注意力。

Full AttnRes：$M$ 是稠密矩阵——每个 $M_{i \to l}$ 都可以独立取任意值，相当于深度维度上的 softmax 注意力。

这个统一视角揭示了一个优美的规律：**现有的残差变体都是深度维度上的线性注意力，AttnRes 是第一个做到深度维度 softmax 注意力的方法**。

### 概念三：online softmax 合并

两阶段推理中，Phase 1 先算跨块注意力，Phase 2 再算块内注意力，最后需要把两组 softmax 结果合并成一个正确的 softmax。

直接合并不行，因为 softmax 的分母（归一化常数）不同。online softmax 的技巧是：在计算每组 softmax 时，同时记录最大值 $m$ 和 log-sum-exp $\ell$，合并时用这两个统计量重新缩放，就能得到精确等价的结果，而不需要重新访问所有数据。

## 餐巾纸速写：思想框架的位移

```
以前大家这么想（标准残差）：
┌─────────────────────────────────────────────────────┐
│  深度 = 一条单向传送带                                │
│                                                     │
│  h1 ──+──→ h2 ──+──→ h3 ──+──→ ... ──→ hL          │
│        ↑         ↑         ↑                        │
│       f1        f2        f3                        │
│                                                     │
│  每层只能看到上一层的输出，权重固定为 1               │
│  信息流：单向、等权、不可选择                         │
└─────────────────────────────────────────────────────┘

这篇论文说应该这么想（AttnRes）：
┌─────────────────────────────────────────────────────┐
│  深度 = 一个可检索的记忆库                            │
│                                                     │
│  h1 ──→ f1 ──→ v1                                   │
│  h2 ──→ f2 ──→ v2    ←── 第 l 层用 w_l 查询         │
│  h3 ──→ f3 ──→ v3    ←── softmax 权重 α_{i→l}       │
│  ...                 ←── 加权求和得到 h_l            │
│                                                     │
│  每层持有一个查询向量，按内容选择性检索前层信息        │
│  信息流：全局可达、权重可学、内容感知                  │
└─────────────────────────────────────────────────────┘

核心位移：从"被动接收累积状态"到"主动检索历史表示"
```

## 博导审稿

**选题眼光**：问题是真实的。PreNorm dilution 不是作者造出来的缺口——SiameseNorm、mHC 等近期工作都在试图解决这个问题，说明社区已经感受到了痛点。把"序列维度的 RNN→Transformer 跃迁"类比到"深度维度"，这个框架很干净，有说服力。选题眼光不错。

**方法成熟度**：方法本身简洁，一个 $d$ 维向量 $w_l$ 加一个 RMSNorm，参数量可以忽略不计。Block AttnRes 的工程设计（跨阶段缓存、两阶段推理）做得扎实，不是纸上谈兵——他们真的在 48B MoE 模型上跑了 1.4T tokens，这不是小打小闹。方法成熟度高。

**实验诚意**：scaling law 实验覆盖 5 个模型尺寸，且明确说明超参数是在 baseline 上调的（对 AttnRes 不利），这个诚意值得肯定。消融实验比较全面，把 DenseFormer、mHC、SWA 等竞争方法都拉进来比了。下游任务覆盖 15 个 benchmark，GPQA-Diamond +7.5 和 Math +3.6 的提升幅度不小。

有一点值得追问：架构搜索实验（Fig. 7）显示 AttnRes 偏好更深更窄的网络，但最终 48B 模型用的是和 baseline 完全相同的架构——如果按 AttnRes 的最优架构重新设计，收益会不会更大？这个问题论文没有回答。

**写作功力**：结构清晰，统一矩阵视角（§6.2）是全文最有理论深度的部分，把一堆看似不相关的方法纳入同一框架，写得很好。附录 B 的推理 I/O 分析也很扎实。

**一句话判决**：**Weak Accept，偏向 Accept**。方法简洁有效，工程落地扎实，理论框架优雅。主要遗憾是没有探索"AttnRes 最优架构"下的完整潜力，以及对 input-dependent query 的取舍分析略显保守。

## 启发

这篇论文照亮了一个我之前没有认真想过的盲区：**残差连接不只是梯度高速公路，它同时定义了深度维度上的信息聚合策略**——而这个策略从 ResNet 诞生以来就从未被认真设计过。

对于做 LLM 架构研究的人，这篇论文提供了一个新的设计维度：序列维度和深度维度是对称的，序列维度上有效的机制（注意力、门控、线性注意力）都可以尝试搬到深度维度上。mHC 是深度线性注意力，AttnRes 是深度 softmax 注意力，那深度 linear attention with gating 呢？深度 flash attention 呢？这个方向还有很多可以探索的空间。

对于工程实践，Block AttnRes 的一个实用结论是：**约 8 个块就能恢复绝大部分收益，推理延迟增加不超过 2%**。这个代价对于换来 GPQA-Diamond +7.5 的提升来说相当划算，值得在新模型设计中认真考虑。

还有一个有趣的观察：AttnRes 的权重热图（Fig. 8）显示，模型学到了"对角线主导 + 嵌入层持续高权重 + 偶发的远程跳连"的模式。这说明网络自发地学会了：大多数时候用最近的层就够了，但有时候需要直接回溯到词嵌入或某个特定的早期层。这个模式和序列注意力中的 attention sink 现象高度相似——深度维度和序列维度的对称性，比我们想象的更深。
